# 0003 — Raspberry Pi Touch Display 2 (7 inch, 720x1280, DSI)

Status: proposed (2026-10-16)

**Context.** Usable for VS Code and a browser, no driver work, powered by the Pi, touch over the same ribbon.

**Decision.** Touch Display 2, rotated to landscape in software. Sets the slab at roughly 190 x 120 mm.

**Alternatives.** 5 inch DSI (lighter, 800x480 too coarse for an editor); 5.5 inch AMOLED HDMI (sharper, more cables and power); 7 inch 1024x600 DSI (cheaper, lower density).

**Consequences.** Big on a forearm. A smaller second slab for the wrist is a phase-4 option, not a compromise now.
