# 0001 — Raspberry Pi OS 64-bit, rebuilt from provisioning stages

Status: proposed (2026-10-16)

**Context.** The device needs first-party support for the DSI display, PCIe NVMe, RTC, power button and the Pi Firefox build, and it must be rebuildable by an AI from a script.

**Decision.** Raspberry Pi OS 64-bit (Bookworm or Trixie, whichever is stable at build time), with every change applied by numbered idempotent stages in provision/.

**Alternatives.** NixOS (declarative, ideal later; Pi 5 support still rough). Ubuntu, Mobian, postmarketOS (touch shells, weaker Pi 5 support). Alpine (rescue SD candidate).

**Consequences.** Manual changes are forbidden by convention; rebuild time is a tracked metric; porting to NixOS later means porting stages, not knowledge.
