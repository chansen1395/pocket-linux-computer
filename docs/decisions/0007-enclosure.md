# 0007 — Enclosure: one slab, GoPro mount standard, OpenSCAD in git

Status: proposed (2026-10-16)

**Context.** Forearm, belt and bag carry from one device; the design must be iterable with an AI.

**Decision.** One core slab holding all electronics, two GoPro female mounts on the back, a shared parametric OpenSCAD library, PETG structural parts and TPU soft parts, versions as git tags.

**Alternatives.** Three purpose-built shells (triple the work). Proprietary quick-release (no ecosystem). FreeCAD or CadQuery as the primary tool (better fillets, less greppable).

**Consequences.** The slab is a little thicker than a purpose-built handheld; the mount accessories cost a few dollars each and already exist.
